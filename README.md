# Pixel-Speed-Slider - A lightweight, ultra-fast WordPress image slider — 8.1KB total, zero dependencies.
Built by jayakrissh.com

### ⚡ Features

- Zero dependencies — no jQuery, no Bootstrap, no external libraries
- Slide & Fade animation modes
- Autoplay with progress bar
- Touch & swipe support (mobile)
- Keyboard navigation
- Pause on hover
- Ken Burns effect
- Lazy load images
- WebP image conversion (48–72% smaller)
- Responsive srcset for mobile
- SEO friendly — real `<img>` tags, Schema.org markup, alt text
- Elementor widget support
- `defer` loading — never blocks page render
- Fully accessible (ARIA roles, keyboard)
